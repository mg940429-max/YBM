# 요청사항
HTML 웹앱: PDF, 이미지를 첨부하면 내부 편집 통일 사항에 맞춰서 교정 교열 결과 보고하는 웹앱을 만들고자 한다.


# 요구기능
0. 학년을 선택하면 해당 학년에 맞는 교육과정을 "조건"에 있는 사이트에서 찾아서 참조하도록 한다.
1. PDF 또는 이미지를 첨부하면 분석(분석 중임을 %로 나타내는 로딩 표시 UI)
2. 분석은 해당 학년의 2022 수학과 교육과정과 내부 편집 통일 사항에 적합한지 판단, 수학적 오류가 있는지 판단, 해당 문제, 풀이가 해당 학년의 교육과정에 벗어나지 않는지 판단함.
3.  2022 수학과 교육과정 / 내부 편집 통일 사항 / 수학적 오류 / 교육과정에 벗어나는지 여부에 대해 해당 4개의 섹션 중 하나라도 부적합한 페이지가 있으면 해당 페이지들에 대한 썸네일들의 미리보기를 하고 각 페이지 썸네일들 누르면 각 섹션별로 결과 보고를 한다.
4. 수정이 필요한 부분은 빨간색으로 BEFORE / AFTER로 나누어서 결과보고한다.
5. 결과 보고 저장 기능 필요

# 조건
1. 내부 편집 통일 사항은 파일 첨부할 예정,
3.  수학과 교육과정은 https://ncic.re.kr/ 에서 찾아서 참조하도록한다.
