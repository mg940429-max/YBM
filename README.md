# 수학도구 AI

수학 문제 검수와 PDF 나누기를 한곳에서 이용하는 웹앱입니다. 검수 도구는 PDF 또는 이미지 문제를 네 기준으로 검토하며, PDF 나누기는 브라우저 안에서 파일을 원하는 범위로 분할합니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

## 주요 기능

- 초등·중등·고등 학년/과목 선택과 NCIC 교육과정 원문 연결
- 내부 편집 통일 사항 파일 첨부
- PDF·이미지 드래그 앤 드롭 업로드
- 단계별 분석 진행률 표시
- 검토가 필요한 페이지 썸네일 및 4개 검수 기준 필터
- 수정 전(BEFORE)·수정 후(AFTER) 비교
- 결과 보고서 TSV 저장
- PDF 전체 페이지 수와 첫 페이지 미리보기
- 페이지 수 기준 균등 분할 또는 직접 범위 지정
- 분할 파일 개별·전체 다운로드 및 지원 브라우저의 폴더 직접 저장

## 무료 로컬 검수

OpenAI API나 API 키를 사용하지 않습니다. PDF의 내장 텍스트는 PDF.js로 읽고, 스캔 PDF와 이미지는 Tesseract.js 한국어·영어 OCR로 인식합니다. 파일 내용은 사용자의 브라우저 안에서만 처리됩니다.

검수는 내장된 2022 개정 교육과정 범위 키워드, 기본 편집 규칙, 단순 사칙연산 검산 규칙을 사용합니다. 첨부 편집 기준은 TXT 또는 텍스트형 PDF를 지원하며 `BEFORE → AFTER` 형태의 줄을 사용자 규칙으로 적용합니다. 생성형 AI가 아니므로 복잡한 수식, 서술형 풀이의 논리, 손글씨는 최종 교정자가 원문과 대조해야 합니다.
