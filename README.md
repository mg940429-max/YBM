# YBM 교과서 AI 모의 심사

교과서 개발 공정에서 교정·교열, 수학적 정확성, 2022 개정 교육과정과 검정 심사 기준 적합성을 사전 점검하는 웹앱입니다. 현재 수학을 지원하며 영어·체육·음악·보건·한문·정보는 후속 개발 대상으로 표시합니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

## 주요 기능

- 수학 과목과 초등·중등·고등 과정 선택
- [NCIC 원문 인벤토리](https://ncic.re.kr/inv/org/list.do)의 2022 개정 수학과 교육과정 참조
- 좌측 메뉴에서 교정·교열 또는 교육과정 적합성 점검 선택
- 내부 편집 통일 사항 PDF·DOCX·TXT 첨부
- PDF·이미지 드래그 앤 드롭 업로드 및 실제 페이지 수 확인
- 분석 진행률과 기준별 처리 상태 표시
- 페이지별 부적합 가능성, 판단 근거와 공식 출처 표시
- 수학적 오류 및 수식의 KaTeX 렌더링
- 수정 전(BEFORE)·수정 후(AFTER) 비교
- 결과 보고서 TSV 저장
- PDF 균등 분할 또는 직접 범위 지정 및 다운로드

## AI 사전 점검

OpenAI Responses API가 PDF·이미지를 분석합니다. 기본 모델은 `gpt-5.6-terra`, 추론 수준은 `high`이며 구조화된 결과와 공식 자료 검색을 사용합니다. API 응답 저장은 비활성화합니다.

배포 환경에는 다음 서버 환경변수를 등록해야 합니다.

```text
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5.6-terra
```

Vercel에서는 환경변수를 Production에 저장한 뒤 새 배포를 생성해야 합니다. API 키는 브라우저 코드에 포함하거나 `NEXT_PUBLIC_` 접두사를 붙이면 안 됩니다.

## 검토 범위와 주의사항

수학과 교육과정은 교육부 고시 제2022-33호 별책 8과 NCIC 학교급별 성취기준을 우선 참조합니다. 교과용도서 검정 관련 절차와 기준은 한국과학창의재단 공식 자료를 우선 참조합니다.

앱의 결과는 편집자가 공식 검정 신청 전에 위험 요소를 찾기 위한 AI 사전 점검이며, 검정기관의 최종 합격·불합격 판정을 대신하거나 합격을 보장하지 않습니다. 편집자는 결과에 표시된 공식 원문과 교과서 PDF를 대조해 최종 판단해야 합니다.
