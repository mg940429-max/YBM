# 수학도구 AI

수학 문제 검수와 PDF 나누기를 한곳에서 이용하는 웹앱입니다. 검수 도구는 PDF 또는 이미지 문제를 네 기준으로 검토하며, PDF 나누기는 브라우저 안에서 파일을 원하는 범위로 분할합니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

## 주요 기능

- 초등·중등·고등 학년/과목 선택과 NCIC 교육과정 원문 연결
- 내부 편집 통일 사항 파일 첨부
- PDF·이미지 드래그 앤 드롭 업로드
- 단계별 분석 진행률 표시
- 검토가 필요한 페이지 썸네일 및 4개 검수 기준 필터
- 수정 전(BEFORE)·수정 후(AFTER) 비교
- 결과 보고서 TSV 저장
- PDF 전체 페이지 수와 첫 페이지 미리보기
- 페이지 수 기준 균등 분할 또는 직접 범위 지정
- 분할 파일 개별·전체 다운로드 및 지원 브라우저의 폴더 직접 저장

## AI 정밀 검수와 로컬 보조 검수

OpenAI Responses API가 설정된 환경에서는 GPT가 PDF·이미지의 문제와 풀이를 직접 다시 풀어 정답, 조건, 선택지, 풀이 논리를 검증합니다. PDF는 `detail: high`, 모델은 기본적으로 `gpt-5.6-terra`, 추론 수준은 `high`를 사용하며 응답 저장은 비활성화합니다.

배포 환경에는 `OPENAI_API_KEY`를 비밀 환경변수로 등록하고 `OPENAI_MODEL`을 필요에 따라 설정합니다. AI 검수 전용 모드이므로 API 키가 없는 환경에서는 로컬 검수로 전환하지 않고 연결 오류를 표시합니다. Vercel에서는 Production 환경변수 등록 후 반드시 새 배포를 생성해야 합니다.

로컬 보조 검수는 내장된 2022 개정 교육과정 범위 키워드, 기본 편집 규칙, 단순 사칙연산 검산 규칙을 사용합니다. 복잡한 수식, 서술형 풀이의 논리, 손글씨는 AI 검수 결과라도 최종 교정자가 원문과 대조해야 합니다.

PDF 내부 글꼴 인코딩이 깨진 페이지는 자동으로 감지해 화면을 OCR로 다시 읽습니다. 계산 오류의 BEFORE/AFTER 수식은 `$...$` 형식의 LaTeX 코드로 보고서에 표시합니다.
