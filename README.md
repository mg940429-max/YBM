# 수학도구 AI

수학 문제 검수와 PDF 나누기를 한곳에서 이용하는 웹앱입니다. 검수 도구는 PDF 또는 이미지 문제를 네 기준으로 검토하며, PDF 나누기는 브라우저 안에서 파일을 원하는 범위로 분할합니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

## 주요 기능

- 초등·중등·고등 학년/과목 선택과 NCIC 교육과정 원문 연결
- 내부 편집 통일 사항 파일 첨부
- PDF·이미지 드래그 앤 드롭 업로드
- 단계별 분석 진행률 표시
- 검토가 필요한 페이지 썸네일 및 4개 검수 기준 필터
- 수정 전(BEFORE)·수정 후(AFTER) 비교
- 결과 보고서 TSV 저장
- PDF 전체 페이지 수와 첫 페이지 미리보기
- 페이지 수 기준 균등 분할 또는 직접 범위 지정
- 분할 파일 개별·전체 다운로드 및 지원 브라우저의 폴더 직접 저장

현재 버전의 분석 결과는 화면 흐름을 검증하기 위한 샘플 데이터입니다. 실제 자동 검수를 위해서는 문서 OCR 및 수학 검수 모델 API를 연결해야 합니다.
